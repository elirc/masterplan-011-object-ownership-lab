# M011: retrieval and transfer workbook

[Expanded workshop map](WORKBOOK-INDEX.md) · [Repository overview](../README.md)

Answer without the source open, then compare with the mentor directions. Use four passes: immediately after study, at your next session, after completing a story, and after working on a later project. This is a suggested practice cadence, not a measured promise about how quickly you will learn.

Use Object.hasOwn before and after shadowing.

**First attempt:** write a three-sentence explanation and one example. Mark confidence as low, medium or high before checking. A confident wrong answer identifies an assumption worth examining; a hesitant right answer may need another independent repetition.

**Second pass:** change one input, ordering or surrounding condition. Predict which part of your answer survives and which part changes. Do not merely replace a fictional name if that leaves the important distinction untouched.

**After a story:** point to one changed line or rule that depends on this concept. Explain why your acceptance check would reject a plausible wrong implementation. If the story does not use this concept directly, say so and choose a relevant part of the unchanged reference instead.

**Transfer pass:** describe a different application where the same reasoning helps. Preserve the distinction, not necessarily the same code or policy. For example, handling a missing value may transfer while the choice to reject it or show an empty state changes with the user need.

## Sort mistakes by cause

Was the error a vocabulary gap, an incorrect trace, a forgotten boundary, a wrong assumption about ownership, or a failure to connect the UI with the core? Choose one primary cause and the smallest exercise that addresses it. Rereading every chapter is often less useful than tracing one difficult transition carefully.

## An independent readiness gate

Without looking, explain `Widget.prototype.describe`, predict an unfamiliar supported example and describe one rejected design. Then open the source and check your explanation. Continue when you can correct a mismatch with evidence rather than merely recognize the reference wording.
